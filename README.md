# CSFC 팀짜기 (Prototype)

CSFC 축구동호회 3팀 운영 도구.
팀장·부팀장 3쌍 고정(현재 시즌: **91년생 이벤트 팀 대전**, 91년생 팀장 3명) → 남은 회원을 팀장 **스네이크 드래프트**로 지명 → 시즌(예: 11월 매주 월요일) 동안 팀 유지 → 경기 당일 참석 체크·공유·기록.

## 빠른 시작

```bash
npm install
cp .env.example .env.local
npm run dev
```

운영진 이메일로 로그인(매직링크) → **① 회원 관리**에서 명단 CSV 등록 → **② 드래프트**에서 차례대로 `지명` → `드래프트 완료` → **③ 경기 당일**에서 참석 체크 → `결과 복사` / `경기 기록 저장`.

- 백엔드: Supabase `csfcSoccer` 프로젝트 (스키마: `supabase/migrations/`)
- 운영진 추가: Supabase `admins` 테이블에 이메일 추가 (자세한 내용은 개발·배포 가이드 5절)

## 주요 기능

- 회원 관리: 추가/수정/삭제, 활동·휴면, CSV·엑셀 붙여넣기 가져오기, CSV 내보내기 (Supabase 저장)
- 드래프트: 스네이크 지명(서버가 차례 계산), 1라운드 순서 변경·추첨, 되돌리기, 완료, 추가 지명
- 경기 당일: 경기일 선택, 팀별 참석 체크, 미배정 자동 배치, 오늘만 이동, 결과 복사, 경기 기록 저장
- 자동 균형 편성 알고리즘(보조): 실력·포지션·GK 균형
- 인증: 운영진 매직링크 로그인, 팀장·부팀장 초대 링크 가입, 허용 목록 + RLS
- 팀 관리(팀장): 경기일 참석, 1경기 기본 + 경기 추가, 포메이션 전술판에 베스트 11 배정, 이미지(PNG) 저장·공유
