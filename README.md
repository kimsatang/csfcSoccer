# CSFC 팀짜기 (Prototype)

CSFC 축구동호회 정기 경기용 3팀 자동 편성 도구.
전체 회원 목록 → 오늘 참석자 체크 → 팀장 3명·부주장 3명 지정 → 실력·포지션이 균형 잡힌 3팀 자동 편성 → 단톡방 공유.

## 빠른 시작

```bash
npm install
cp .env.example .env.local
npm run dev
```

운영진 이메일로 로그인(매직링크) → 회원이 없으면 `샘플 데이터`로 24명 추가 → **② 참석·역할**에서 `전체 참석` → 팀장 3명, 부주장 3명 지정 → `3팀 짜기` → `경기 기록 저장`.

- 백엔드: Supabase `csfcSoccer` 프로젝트 (스키마: `supabase/migrations/`)
- 운영진 추가: Supabase `admins` 테이블에 이메일 추가 (자세한 내용은 개발·배포 가이드 5절)

## 주요 기능

- 회원 관리: 추가/수정/삭제, 활동·휴면, CSV·엑셀 붙여넣기 가져오기, CSV 내보내기 (Supabase 저장)
- 참석·역할: 참석 체크, 팀장/부주장 각 3명 지정 (정원 초과 방지)
- 자동 편성: 팀장·부주장 1명씩 고정, 인원 차 ≤1, 평균 실력·포지션·GK 균형
- 결과: 팀원 수동 이동, 다시 섞기, 균형도 표시, 실력 숨김, 단톡방용 텍스트 복사, 경기 기록 저장
- 인증: 운영진 매직링크 로그인, 허용 목록 + RLS
