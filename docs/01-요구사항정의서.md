# CSFC 팀짜기 — 요구사항 정의서 (Prototype v0.4)

## 1. 배경과 목표

CSFC 축구동호회는 정기 경기 때마다 참석 인원을 3팀으로 나눠 로테이션 경기를 한다. 지금은 운영진이 손으로 팀을 짜다 보니 시간이 걸리고, 실력·포지션이 한쪽으로 쏠리는 일이 생긴다.

**목표:** 팀장·부팀장 3쌍을 정하고 남은 회원을 팀장들이 스네이크 드래프트로 뽑아 시즌(예: 11월 매주 월요일) 동안 유지할 3팀을 만든다. 경기 당일에는 참석자만 체크하면 팀별 명단이 나오고 단톡방 공유·기록 저장까지 한다.

> 2026-11-04 변경: 매 경기 자동 균형 편성 → **시즌 고정팀 + 팀장 드래프트**. 상세는 `05-시즌-드래프트.md`. 자동 균형 알고리즘(03 문서)은 코드에 남겨 두고 미배정 참석자 자동 배치에 일부 활용.

## 3. 사용자

- **운영진(편성 담당)**: 회원 데이터 관리, 경기 당일 참석·역할 지정, 편성 결과 공유. `admins`에 등록된 이메일로 로그인한 사람만 사용 가능.
- **일반 회원**: 공유된 결과를 단톡방에서 확인 (앱 직접 사용 X).

## 4. 기능 요구사항

### F1. 회원 관리
- F1-1 회원을 추가·수정·삭제할 수 있다. 필수: 이름, 주포지션, 실력(1~10).
- F1-2 회원을 '휴면'으로 바꾸면 참석 체크 목록에서 빠진다(데이터는 유지).
- F1-3 CSV 또는 엑셀에서 복사한 표를 붙여넣어 일괄 등록할 수 있다. (기존 회원에 추가. 경기 기록 보호를 위해 전체 교체는 제공하지 않음)
- F1-4 잘못된 행은 행 번호와 이유를 보여주고 나머지 행은 등록한다.
- F1-5 회원 목록을 CSV로 내보낼 수 있다(백업·엑셀 편집용).

### F2'. 시즌 드래프트 (v0.4, 05 문서)
- 시즌별 3팀은 팀장·부팀장이 고정되어 있다.
- 남은 활동 회원을 스네이크 순서로 지명한다. 현재 차례 팀과 다음 순서를 표시한다.
- 첫 지명 전 1라운드 순서를 바꾸거나 추첨할 수 있다.
- 마지막 지명을 되돌릴 수 있고, 완료하면 팀이 확정된다. 신입은 추가 지명으로 넣는다.

### F2''. 경기 당일 (v0.4)
- 경기일(시즌의 매주 경기 요일)을 고르고 팀별 명단에서 참석자를 체크한다.
- 미배정 참석자를 직접 또는 자동으로 팀에 넣고, 인원 차가 크면 '오늘만 이동'으로 조정한다.
- 결과를 복사하고 경기 기록으로 저장한다.

### (v0.3 이전) F2. 참석·역할 지정 — 드래프트 도입으로 화면에서 제거
- F2-1 활동 회원 중 오늘 참석자를 체크한다. 전체 참석/전체 해제를 지원한다.
- F2-2 참석자에게 역할(일반/팀장/부주장)을 지정한다. 역할을 지정하면 자동으로 참석 처리된다.
- F2-3 팀장·부주장은 각각 최대 3명까지만 지정되며, 정원이 차면 버튼이 비활성화된다.
- F2-4 참석 인원, 팀장/부주장 지정 현황, 팀당 예상 인원을 실시간으로 표시한다.
- F2-5 팀장 3명·부주장 3명이 정확히 지정돼야 '3팀 짜기'가 활성화된다.

### F3. 자동 편성
- F3-1 각 팀에 팀장 1명·부주장 1명이 반드시 배치된다.
- F3-2 팀 간 인원 차이는 1명 이하.
- F3-3 팀 평균 실력 차이를 최소화한다.
- F3-4 수비/미드/공격 인원이 팀마다 고르게 분포한다.
- F3-5 GK 가능자(주 또는 부포지션 GK)가 3명 이상이면 모든 팀에 1명 이상 배치한다.
- F3-6 '다시 섞기'를 누르면 균형도는 비슷하지만 다른 조합이 나온다.
- 상세 규칙은 `03-팀편성-알고리즘.md` 참고.

### F4. 결과 확인·조정·공유
- F4-1 팀별 인원, 평균 실력, 포지션 분포, 팀장/부주장 뱃지를 보여준다.
- F4-2 팀원(팀장·부주장 제외)을 다른 팀으로 옮길 수 있고, 통계·균형도가 즉시 다시 계산된다.
- F4-3 전체 균형도(아주 균형/균형/보통/불균형)를 표시한다.
- F4-4 경기 제목(기본: `CSFC 11/8(일) 팀 편성`)을 수정할 수 있다.
- F4-5 '결과 복사'로 단톡방용 텍스트를 클립보드에 복사한다.
- F4-6 '실력 표시'를 끄면 화면과 공유 텍스트에서 실력 수치를 숨긴다.
- F4-7 '경기 기록 저장'으로 경기일·제목·팀 배정을 DB에 저장한다.

### F5. 인증
- F5-1 이메일을 입력하면 로그인 링크(매직링크)를 받는다.
- F5-2 `admins`에 없는 이메일은 로그인해도 '운영진 아님' 화면만 보이고 데이터에 접근할 수 없다(RLS).

## 5. 비기능 요구사항

| 항목 | 기준 |
|---|---|
| 모바일 | 경기장에서 휴대폰으로 사용 — 390px 폭에서 모든 기능 사용 가능 |
| 성능 | 참석 40명 기준 편성 1초 이내 (현재 24명 기준 수십 ms) |
| 저장 | 회원·경기 기록은 Supabase에 저장되어 여러 기기·운영진이 공유 |
| 개인정보 | 연락처·생년월일 등은 프로토타입에서 수집하지 않음. 실력 점수는 운영진만 보는 민감 정보로 취급(공유 시 기본 숨김 옵션 제공) |
| 배포 | Vercel 정적 배포, main 브랜치 push 시 자동 배포 |

## 6. 화면 구성

1. **① 회원 관리** — 입력 폼, CSV 가져오기(같은 이름은 갱신)/내보내기, 회원 테이블
2. **② 드래프트** — 지금 차례 배너, 3팀 로스터(지명 번호), 지명 가능 회원(포지션 필터·검색·지명 버튼), 순서 설정·추첨, 되돌리기, 완료
3. **③ 경기 당일** — 경기일 선택, 팀별 참석 체크, 팀별 참석 명단·통계, 미배정 배치, 오늘만 이동, 결과 복사·기록 저장
