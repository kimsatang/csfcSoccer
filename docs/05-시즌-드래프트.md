## 2. 드래프트 규칙

- 지명 순서: 1라운드 1→2→3, 2라운드 3→2→1, 3라운드 1→2→3 … (스네이크)
- 1라운드 순서는 첫 지명 전까지 화면에서 바꾸거나 **순서 추첨** 가능. 첫 지명 이후 잠금.
- 지명 대상: 활동 회원 중 팀장·부팀장이 아니고 아직 지명되지 않은 사람
- **나이대 그룹**: 지명 목록을 나이대별로 묶어 보여주고(끄기 가능), 나이대 필터로 한 그룹만 볼 수 있다. 팀 카드에는 팀별 나이대 인원이 표시되어 나이대가 한 팀에 쏠리는지 바로 보인다.
  - 그룹 경계는 `src/entities/player/age.ts`의 `AGE_GROUPS` 한 곳에서 수정 (현재 ~79 / 80~84 / 85~87 / 88~)
  - 운영 예: "1~3라운드는 70년대생에서만" 같은 규칙은 지금은 팀장들 합의로 진행하고, 필요하면 라운드별 나이대 제한을 서버 규칙(`make_pick`)으로 추가
- 차례(어느 팀이 지명하는지)는 **서버가 계산**한다(`make_pick`). 여러 폰에서 동시에 눌러도 순서가 꼬이지 않는다.
- 실수하면 **지명 되돌리기**(마지막 1명 취소, 2번 클릭 확인)
- 모두 뽑으면 **드래프트 완료** → 시즌 상태 ACTIVE(팀 확정)
- 시즌 중 신입이 들어오면 **추가 지명** 버튼으로 다시 열어 이어서 지명

## 3. 경기 당일 흐름

1. ③ 경기 당일 → 경기일 선택(기본: 다음 월요일)
2. 팀별로 묶인 명단에서 참석자 체크 (팀 미배정 회원은 별도 그룹)
3. 팀별 참석자, 인원, 평균 실력, 포지션 분포가 자동 표시
4. 미배정 참석자는 직접 팀 지정 또는 **자동 배치**(인원 적은 팀 → 평균 실력 낮은 팀)
5. 인원 차가 2명 이상이면 경고 → **오늘만 이동**으로 조정 (시즌 팀은 바뀌지 않음, '임시' 표시)
6. **결과 복사**(단톡방) → **경기 기록 저장**(경기일·팀 배정·팀장/부팀장 역할, 시즌 연결)

참석 체크와 오늘만 이동은 경기일별로 기기에 임시 저장되고, 기록 저장 시 DB에 남는다.
