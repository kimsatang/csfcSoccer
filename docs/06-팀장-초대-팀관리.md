# CSFC 팀짜기 — 팀장 초대 & 팀 관리(전술판)

2026-11-04 추가. 팀장·부팀장이 각자 폰으로 들어와 **드래프트 지명**과 **경기일별 팀 구성·라인업**을 직접 관리한다.

## 1. 역할과 권한

| 기능 | 운영진 | 팀장·부팀장 |
|---|---|---|
| 운영진 추가·삭제 | 슈퍼 관리자(김동인)만 | ✗ |
| 회원 관리(추가·수정·삭제) | ✅ | ✗ (조회만) |
| 드래프트 지명 | 모든 차례 | **자기 팀 차례에만** |
| 지명 순서 변경·되돌리기·완료 | ✅ | ✗ |
| 팀 관리(참석·라인업·이미지) | 3팀 모두 | **자기 팀만** |
| 경기 당일(전체 참석·기록 저장) | ✅ | ✗ |
| 초대 링크 관리 | ✅ | ✗ |

권한은 DB(RLS)에서 막는다. 화면을 조작해도 다른 팀 라인업 저장·다른 팀 차례 지명은 서버에서 거부된다.

> 팀장·부팀장도 회원 목록(실력 점수 포함)을 **조회**할 수 있다. 드래프트에 필요해서 열어 둔 것이며, 실력 점수를 숨기려면 별도 뷰로 분리해야 한다(보완 후보).

## 2. 초대 링크 가입 흐름

1. 운영진: **팀 관리 → 팀장·부팀장 초대 링크** → `전체 링크 복사 (단톡방용)` 또는 사람별 `링크 복사`
2. 팀장: 링크 열기 → "남상혁팀 팀장 · 남상혁 초대" 확인 → 이메일 입력 → **인증번호 받기**
3. 메일의 **인증번호를 같은 화면에 입력**(권장 — 카톡 인앱 브라우저에서도 그대로 진행) 또는 메일의 링크 클릭
4. "이 계정을 남상혁팀 팀장으로 등록" 확인 → **등록하고 시작하기**
5. 이후에는 같은 이메일로 로그인하면 바로 팀장 화면(드래프트 / 팀 관리)

> 인증번호가 메일에 나오려면 Supabase **Authentication → Email Templates → Magic Link** 본문에 `{{ .Token }}`이 들어 있어야 한다 (5절 체크리스트).

- **지정 이메일 자동 연결**: `team_invites.preassigned_email`에 이메일을 넣어 두면, 그 이메일로 **처음 로그인할 때** 초대 링크 없이 자동 등록된다 (`auth.users` 생성 트리거).
  - 현재: **김동인(`ehddls128@gmail.com`) = 슈퍼 관리자 겸 김동인팀 팀장**으로 지정됨
- 링크 하나는 **한 계정만** 등록 가능. 다른 계정이 쓰면 거부된다.
- 잘못 등록됐거나 링크가 퍼졌으면 운영진이 **재발급** → 이전 링크 무효. (이미 등록된 계정의 권한은 유지 — 권한 회수는 Supabase `team_leaders`에서 행 삭제)
- 로그인 상태에서 링크를 열어도 **확인 단계**가 있어, 운영진이 테스트로 남의 링크를 열어도 자동 등록되지 않는다.

## 3. 팀 관리 화면

### 3-1. 경기일·참석자
- 시즌 경기일(11/9·16·23·30) 중 선택. 기본은 다음 경기일.
- 팀원(팀장·부팀장·지명 선수) 칩을 눌러 참석 체크 → **자동 저장**
- `+ 다른 회원(용병) 추가`: 드래프트 미배정·다른 팀 회원을 그날만 추가
- 불참으로 바꾸면 모든 경기 라인업에서 자동으로 빠짐
- 운영진 **경기 당일** 화면의 `팀장 입력 불러오기`로 3팀 참석자를 한 번에 가져올 수 있음

### 3-2. 경기 (1경기 기본 + 경기 추가)
- 경기일마다 **1경기**가 기본. `+ 경기 추가`로 2경기, 3경기 … (최대 10)
- 새 경기는 **직전 경기 라인업을 복사**해서 시작 → 교체만 손보면 됨
- 경기마다 **포메이션·상대 팀·라인업**을 따로 저장
- `경기 삭제`(2번 눌러 확인), 1경기만 남으면 삭제 버튼 숨김

### 3-3. 전술판 (베스트 11)
- 포메이션: 4-4-2, 4-3-3, 4-2-3-1, 4-1-4-1, 3-5-2, 3-4-3, 5-3-2
- 자리(원)를 누르면 아래에서 선수 목록이 올라옴 → 선택
  - 다른 자리에 있던 선수를 고르면 **두 자리를 맞바꿈**
  - `이 자리 비우기`
- `빈자리 자동 채우기`: 교체 명단에서 자리별 주/부 포지션이 맞는 선수 우선, GK 자리는 GK만
- 포메이션을 바꿔도 배정된 11명은 유지(같은 자리 → 그대로, 나머지는 빈자리에 순서대로)
- 오른쪽(모바일은 아래) **교체/미배정** 목록과 `선발 n/11`

### 3-4. 이미지 저장
- 1080×1500 PNG: 팀명, 경기일·경기 번호·상대·포메이션, 경기장 위 선수 배치, 교체 명단, 시즌명
- 휴대폰: 공유 시트(카톡으로 바로 전송), PC: 파일 다운로드
- 저장이 막히는 환경(일부 인앱 브라우저)을 위해 화면에 미리보기 이미지도 띄움 → 길게 눌러 저장

## 4. 데이터

| 테이블 | 내용 |
|---|---|
| `team_invites` | 초대 토큰, 시즌 팀, 역할(CAPTAIN/VICE), 대상 회원, 가입 계정·시각 |

## 5. 운영 체크리스트

- [ ] Supabase Auth → URL Configuration → Redirect URLs에 배포 주소 `https://<도메인>/**` 등록 (초대 토큰이 쿼리로 붙음)
- [ ] 초대 링크 6개 단톡방/개인톡 전달

## 6. 드래프트 실시간 반영

- 지명·되돌리기·순서 변경·완료가 **모든 폰에 즉시** 반영 (Supabase Realtime, `draft_picks`·`seasons` 구독)
- 화면의 `● 실시간` 표시로 연결 상태 확인. 연결이 끊겨도 20초마다, 앱으로 돌아올 때마다 새로 불러옴
- Realtime도 RLS를 따르므로 운영진·팀장만 이벤트를 받음
