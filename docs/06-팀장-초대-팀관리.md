## 2. 초대 링크 가입 흐름

1. 운영진: **팀 관리 → 팀장·부팀장 초대 링크** → `전체 링크 복사 (단톡방용)` 또는 사람별 `링크 복사`
2. 팀장: 링크 열기 → "남상혁팀 팀장 · 남상혁 초대" 확인 → 이메일 입력 → **인증번호 받기**
3. 메일의 **인증번호를 같은 화면에 입력**(권장 — 카톡 인앱 브라우저에서도 그대로 진행) 또는 메일의 링크 클릭
4. "이 계정을 남상혁팀 팀장으로 등록" 확인 → **등록하고 시작하기**
5. 이후에는 같은 이메일로 로그인하면 바로 팀장 화면(드래프트 / 팀 관리)

> 인증번호가 메일에 나오려면 Supabase **Authentication → Email Templates**의 **Confirm sign up**(첫 가입)과 **Magic Link**(재로그인) 본문 모두에 `{{ .Token }}`이 들어 있어야 한다 (5절 체크리스트).

- **지정 이메일 자동 연결**: `team_invites.preassigned_email`에 이메일을 넣어 두면, 그 이메일로 **처음 로그인할 때** 초대 링크 없이 자동 등록된다 (`auth.users` 생성 트리거).
  - 현재: **김동인(`ehddls128@gmail.com`) = 슈퍼 관리자 겸 김동인팀 팀장**으로 지정됨
- 링크 하나는 **한 계정만** 등록 가능. 다른 계정이 쓰면 거부된다.
- 잘못 등록됐거나 링크가 퍼졌으면 운영진이 **재발급** → 이전 링크 무효. (이미 등록된 계정의 권한은 유지 — 권한 회수는 Supabase `team_leaders`에서 행 삭제)
- 로그인 상태에서 링크를 열어도 **확인 단계**가 있어, 운영진이 테스트로 남의 링크를 열어도 자동 등록되지 않는다.

## 3. 팀 관리 화면

### 3-1. 경기일·참석자
- 시즌 경기일(11/9·16·23·30) 중 선택. 기본은 다음 경기일.
- 팀원(팀장·부팀장·지명 선수) 칩을 눌러 참석 체크 → **자동 저장**
- `+ 다른 회원(용병) 추가`: 드래프트 미배정·다른 팀 회원을 그날만 추가
- 불참으로 바꾸면 모든 경기 라인업에서 자동으로 빠짐
- 운영진 **경기 당일** 화면의 `팀장 입력 불러오기`로 3팀 참석자를 한 번에 가져올 수 있음

### 3-2. 경기 (1경기 기본 + 경기 추가)
- 경기일마다 **1경기**가 기본. `+ 경기 추가`로 2경기, 3경기 … (최대 10)
- 새 경기는 **직전 경기 라인업을 복사**해서 시작 → 교체만 손보면 됨
- 경기마다 **포메이션·상대 팀·라인업**을 따로 저장
- 경기 메뉴(⋯) → `경기 삭제`(확인 창), 1경기만 남으면 삭제 메뉴 숨김
- 운영진은 다른 팀 화면을 **조회만** 가능(입력 잠김, 이미지 저장은 가능)

### 3-3. 전술판 (베스트 11)
- 포메이션: 4-4-2, 4-3-3, 4-2-3-1, 4-1-4-1, 3-5-2, 3-4-3, 5-3-2
- **포지션별 색**: GK 노랑 · DF 파랑 · MF 청록 · FW 빨강 (빈자리는 테두리만, 선수 배정 시 채움). 경기장 아래 범례, 라인업 이미지에도 같은 색
- 자리(원)를 누르면 아래에서 선수 목록이 올라옴 → 선택
  - 다른 자리에 있던 선수를 고르면 **두 자리를 맞바꿈**
  - `이 자리 비우기`
- **드래그로 자리 이동** (폰 터치·PC 마우스 모두)
  - 경기장 선수를 다른 자리로 끌기 → 빈자리면 이동, 선수가 있으면 **맞바꿈**
  - 교체 명단 선수를 경기장 자리로 끌기 → 투입(그 자리 선수는 교체로)
  - 경기장 선수를 교체 영역으로 끌기 → 교체로 빼기
  - 끄는 중 화면 위·아래 끝에 가까우면 자동 스크롤, 살짝 누르기만 하면 기존처럼 선수 선택창
- `빈자리 자동 채우기`: 교체 명단에서 자리별 주/부 포지션이 맞는 선수 우선, GK 자리는 GK만
- 포메이션을 바꿔도 배정된 11명은 유지(같은 자리 → 그대로, 나머지는 빈자리에 순서대로)
- 오른쪽(모바일은 아래) **교체/미배정** 목록과 `선발 n/11`

### 3-4. 이미지 저장
- 1080×1500 PNG: 팀명, 경기일·경기 번호·상대·포메이션, 경기장 위 선수 배치, 교체 명단, 시즌명
- 휴대폰: 공유 시트(카톡으로 바로 전송), PC: 파일 다운로드
- 저장이 막히는 환경(일부 인앱 브라우저)을 위해 화면에 미리보기 이미지도 띄움 → 길게 눌러 저장

## 7. 최종 명단 (명단 탭)

- 운영진·팀장·부팀장 모두 볼 수 있는 탭. 드래프트 중이면 "지금까지 지명된 명단 기준" 안내와 함께 표시
- 정렬: 지명순 / 나이순 / 포지션순 (이미지에도 같은 순서로 반영)
- 팀 카드: 팀장·부팀장, 지명 선수(지명 번호는 표시하지 않음), 나이대·포지션 인원, 참석률
- **이미지 저장**
  - `3팀 한 장으로 이미지 저장`: 1080px 폭, 3열(팀별 색 헤더, 팀장 C·부팀장 V, 이름·년생·포지션)
  - 팀 카드의 `이미지 저장`: 팀 1장(1080×1350 이상), 팀장·부팀장 카드 + 선수 2열
  - 휴대폰은 공유 시트(카톡 바로 전송), PC는 다운로드, 미리보기 이미지는 길게 눌러 저장
  - 실력 점수는 이미지에 넣지 않음
- 메뉴(⋯) → 텍스트로 복사(단톡방용)

## 8. 경기 당일 — 카톡 투표 가져오기 (스크린샷 / 글 붙여넣기)

경기 당일 → 참석 체크 → `카톡 투표 가져오기`

- **스크린샷**: 카톡 투표의 투표자 목록 화면 캡처를 여러 장 골라도 됨(순서대로 이어 붙임)
  - 브라우저 안에서 글자 인식(tesseract.js, 한국어 데이터 약 1.5MB는 처음 한 번만 내려받음). 이미지는 서버로 보내지 않고 저장하지 않음
  - 원본 + 보정본(2배 확대·흑백) 두 번 인식해 합침 → 실제 예시 2장(축구 15명, 풋살 13명) 모두 100% 인식
  - 익명 투표는 투표자가 안 보여 인식 불가
- **글 붙여넣기**: 줄바꿈·쉼표·슬래시 등 아무 구분, 번호·호칭·괄호·지역 무시, 띄어 쓴 이름(`김 진`), 지역이 붙은 이름(`정태호하남`)
- **투표 항목**: `1일 일요일 18시 ~ 20시 축구 : 15명` 같은 제목 줄로 항목을 나눔 → 여러 항목이면 골라서 적용
- **투표 인원(검증용, 선택)**: 제목의 `15명`·`(15)`·`총 15명`을 자동으로 읽고, 직접 입력·수정 가능
  - 체크 인원과 같으면 초록 "모두 찾았어요", 다르면 빨강 "n명 누락 가능" + 적용 시 한 번 더 확인
- **카톡 닉네임 `77 이성흠 하남_…`**: 이름 앞 두 자리 숫자를 년생으로 사용
  - 이 형식이 많으면 년생 숫자 바로 뒤 단어만 이름 후보로 봄 → 프로필 사진 글자·지역명 잡음 제거
- **동명이인**: 년생으로 한 명으로 좁혀지면 자동, 아니면 "동명이인 — 누구인지 골라 주세요"에서 선택(년생·포지션 표시)
- **한 글자 오타**(인식 오류 포함): 년생이 맞으면 자동 보정(✎ 표시), 아니면 "혹시 이 사람인가요?" 제안
- 체크된 회원 칩의 ✕로 빼기, `직접 추가`(이름 검색)로 넣기, 회원 목록에 없는 이름·휴면 회원·불참으로 뺀 이름 안내
- 적용 방식: `이 명단으로 바꾸기`(기존 체크 해제) / `기존 체크에 추가`
- 코드: `src/features/attendance/parseNames.ts`(+ 테스트 15개, 실제 스크린샷 인식 결과 포함), `ocr.ts`, `PasteAttendance.tsx`
- 다음 후보: 확인한 닉네임↔회원 연결을 별칭으로 저장해 다음부터 자동 인식, 회원이 직접 응답하는 투표 링크

## 9. 경기 당일 참석 → 팀 관리 반영

- 운영진이 경기 당일 화면에서 참석을 바꾸면(칩 체크, 명단 붙여넣기, 전체 참석/해제, 오늘만 팀 이동) **바뀐 회원만** 각 팀의 팀 관리 참석에 반영
  - 참석 → 그날 뛰는 팀의 참석자에 추가 (오늘만 다른 팀으로 옮긴 회원은 옮긴 팀에)
  - 불참·팀 이동 → 원래 팀의 참석자와 그날 라인업 자리에서 빠짐
  - 화면을 처음 열 때는 아무것도 보내지 않음 → 팀장이 입력해 둔 참석은 그대로
- 상단 배지: `팀 관리 반영 중` / `팀 관리에 반영됨` / `반영 실패`
- DB: `apply_day_attendance(date, changes)` — 운영진 전용, 팀 관리 쓰기 검사는 이 함수 안에서만 통과
- 마이그레이션: `supabase/migrations/20261105132054_day_attendance_sync.sql` (적용 완료)
