# CSFC 팀짜기 — 개발·배포 가이드

## 1. 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | React 19 + TypeScript | 팀 표준 |
| 빌드 | Vite 8 | 빠른 개발 서버, 정적 빌드 |
| 상태 | `useReducer` + localStorage | 프로토타입 단계에서 서버 없이 동작 |
| 테스트 | Vitest | 편성 알고리즘 단위 테스트 |
| 배포 | Vercel (정적) | 무료 플랜, GitHub 연동 자동 배포, 프리뷰 URL |
| 스타일 | 순수 CSS (CSS 변수) | 의존성 최소화. 화면이 늘면 UI 키트 도입 검토 |

## 2. 폴더 구조 (FSD 경량 적용)

```
src/
├─ app/                  # 앱 진입, 전역 상태, 전역 스타일
│  ├─ App.tsx            # 3단계 탭 (회원 관리 / 참석·역할 / 팀 편성)
│  ├─ store.ts           # reducer + localStorage 동기화
│  └─ styles.css
├─ entities/player/      # 선수 도메인
│  ├─ model.ts           # 타입, 포지션, 상수
│  ├─ csv.ts             # CSV 가져오기/내보내기
│  └─ sample.ts          # 샘플 회원 24명
├─ features/build-teams/ # 팀 편성 기능
│  ├─ buildTeams.ts      # 알고리즘, 수동 이동
│  ├─ buildTeams.test.ts
│  └─ exportText.ts      # 단톡방 공유 텍스트
├─ widgets/              # 화면 단위 컴포넌트
│  ├─ MemberManager.tsx
│  ├─ MatchSetup.tsx
│  └─ TeamBoard.tsx
└─ shared/lib/           # rng(시드 난수), storage
```

## 3. 로컬 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 알고리즘 테스트
npm run build    # dist/ 생성 (tsc 타입체크 포함)
npm run preview  # 빌드 결과 확인
```

Node 20 이상 권장.

## 4. Vercel 배포

### 최초 1회
1. GitHub에 저장소 생성 후 push (예: `csfc-team-maker`)
2. vercel.com → **Add New → Project** → 저장소 Import
3. Framework Preset이 **Vite**로 자동 인식되는지 확인 (Build `npm run build`, Output `dist`)
4. **Deploy** → `https://csfc-team-maker.vercel.app` 형태의 URL 발급

`vercel.json`에 SPA rewrite가 들어 있어 이후 라우터를 추가해도 새로고침 404가 나지 않는다.

### 이후
- `main` 브랜치 push → 프로덕션 자동 배포
- PR 생성 → 프리뷰 URL 자동 생성 (운영진에게 미리 보여주기 좋음)

### CLI로 배포할 경우
```bash
npm i -g vercel
vercel        # 프리뷰
vercel --prod # 프로덕션
```

## 5. 데이터 저장 주의 (프로토타입)

- 데이터는 **사용 중인 브라우저의 localStorage에만** 저장된다. 다른 폰·PC에서는 보이지 않는다.
- 폰을 바꾸거나 브라우저 데이터를 지우면 사라지므로, **회원 관리 → CSV 내보내기**로 주기적으로 백업한다.
- 운영진 여러 명이 같이 써야 하면 다음 단계(서버 저장)로 넘어간다.
